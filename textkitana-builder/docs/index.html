1. Overview

Kitana Builder merges a conversational IDE, offline AI generation powered by Ollama, and operational tooling for packaging full-stack applications into portable web or desktop distributions.

  • Offline-first: no internet required beyond Ollama model setup.
  • Agentic workflows: autonomy slider, scheduled tasks, and policy enforcement.
  • Packaging pipeline: ExeOutput for PHP 2025.0 configuration baked in.

2. Initial Setup

  1. Install PHP 8.1+, SQLite support, and enable exec().
  2. Install Ollama and pull required models: ollama pull codellama and ollama pull llama3.2.
  3. Serve the project directory via Apache/Nginx or php -S localhost:8000.
  4. Visit /install.php to create the SQLite database and verify Ollama.
Ollama service tips
  • Run ollama serve prior to launching Kitana Builder.
  • Check available models via Settings → Ollama Status.
  • Use Manage Models to pull or remove models directly.

5. Autonomous Agents

Use Agent Mode to chain tasks.

  1. Set Autonomy slider (0 suggestions → 2 full execution).
  2. Provide a goal such as "Generate unit tests and run phpunit".
  3. Review planned actions and apply them manually or via scripts.

6. Scheduler & Tasks

Create cron-like reminders stored in SQLite and surfaced in the calendar view. Ideal for backups, nightly builds, or recurring QA scripts. Tasks integrate with PHP daemons or OS-level schedulers.

7. Packaging to Windows .exe

  1. Install ExeOutput for PHP 2025.0 (WebView2 engine enabled).
  2. Run build.php to refresh the project file inside /package/kitana-project.php2exe.
  3. Open ExeOutput → load the generated project → confirm encryption & ZSTD compression.
  4. Compile to produce kitana-builder.exe (~20–50 MB).
  5. Bundle ollama-launcher.bat to start Ollama alongside the app.
Offline distribution tips
  • Embed pulled Ollama models on the target machine before launch.
  • Use package/exebuild.ini to configure icons and splash screens.
  • Post-build hook compresses templates and verifies database integrity.

8. FAQ

How do I add new templates?

Place scaffolds in /projects/templates (create folder) and reference via chat prompts or the project creation modal.

How is security handled?

All inputs sanitized via includes/functions.php, CSRF + rate limiting via includes/security.php. Security scans accessible under Settings → Security Tools.

Can I extend Kitana Builder?

Yes. Add PHP APIs inside /api/, register in assets/js/main.js, and expose via the UI. Plugins can wrap CLI tools or custom Ollama prompts.
